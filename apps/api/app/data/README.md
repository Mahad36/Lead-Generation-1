# Bundled data

`world_cities.json`: the 15 largest cities (by population) of every country, used for the "Suggested places"
on the Scraping page. Built from [GeoNames](https://www.geonames.org/) (`cities15000` + `admin1CodesASCII`),
licensed under [Creative Commons Attribution 4.0](https://creativecommons.org/licenses/by/4.0/). Country names
match the `country-state-city` package used by the location picker.
